🔎 Escenarios

Los tres escenarios predefinidos conservan el mismo estímulo cardíaco para comparar únicamente R y C.

Referencia: R = 1.10, C = 1.50.
Más rigidez: R = 1.10, C = 0.75.
Mayor resistencia: R = 1.50, C = 1.50.
Personalizado: usa tus controles R y C.
Solo cambiamos la distensibilidad en el caso de arterias rígidas y la resistencia en el otro, para aislar sus efectos.

🧮 Ecuación diferencial

Qin(t) = C · dP/dt + P/R

El corazón entrega un flujo pulsátil Qin(t). Parte de ese flujo distiende las arterias (término C·dP/dt) y otra parte sale hacia la periferia (P/R).

El flujo de entrada se representa con un pulso semisenoidal de volumen 70 mL por latido en el caso inicial, con una duración sistólica del 35 % de cada ciclo.

🫀 Interpretación y límites

Menor C: la misma entrada de sangre genera oscilaciones mayores de presión, porque el reservorio arterial es menos distensible.

Mayor R: aumenta la presión media en el modelo cuando el flujo medio se mantiene constante.

Limitaciones: R y C son constantes; el modelo concentra todas las arterias en un compartimento. No describe ondas reflejadas, inercia de la sangre, distribución espacial ni mecanismos de regulación cardiovascular.
